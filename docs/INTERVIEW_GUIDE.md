# 面试讲解与复现要点

如果还不熟悉模型，先读[模型白话讲解](MODELS_EXPLAINED.md)：从业务目标、生活化例子和手算入手，再回到这里练习追问。

## 先用90秒讲清一次业务判断

“我从一个异常入手：2011年11月可识别买家同比增加3.36%，购买金额却下降1.68%，是否应该扩大补贴？先核对范围，发现全量商品净额其实增长2.34%。再固定历史高购买额名单，追到跨月与同客户：整组9—11月转正，但21名11月减额客户中18人宽窗仍减少，不能用提前采购解释掉问题。海外又收窄到澳洲集中采购和德国既有买家的篮子；商品进一步区分单张大单与广泛成交价档变化。因此交付的是具体客户/商品核查、需要补的数据及进入补贴实验的条件。

“另一套真实随机实验用来回答定向营销是否值得增加投入。平均触达有效，但同容量下模型定向相对随机触达的收入差区间是−$0.279到$0.267/人，现有数据不能确认商业优势。我拆开选人和选内容，保留不确定性，并把实施成本换算成必须超过的收入门槛，再计算下一轮独立验证的样本要求。两套数据来自不同商家，我没有把它们拼成同一条因果链。”

## 业务追问：结论怎样改变行动？

1. **你推翻了什么初始解释？** “可识别金额下降”不等于“全量净额下降”；“平均成交单位金额下降”不等于“所有商品降价”；平均触达效果不等于定向增益。每个解释都用同范围的账簿、分组或实验对比检验。
2. **为何固定38人，而不直接剔除当前最大客户？** 名单按2010年1—10月金额排序，早于两个待比较11月，避免按当期结果挑人。不过这是回顾诊断，并未预注册；历史前1%也不是企业客户身份。名单外包含历史未覆盖客户，不能称全部都是小客户。
3. **这是否证明客户流失导致收入下降？** 没有。固定名单分析定位金额缺口；同期未买可能是采购周期移动。要看更长窗口、采购意向、订单取消和库存。不能把缺口金额当成发券可追回收益。
4. **给商品运营什么具体问题？** 三层蛋糕架件数1938→942，而成交单位金额£11.43→£11.72，应查销量、订单构成与可得性；木星形圣诞装饰件数891→4980、单位金额£0.85→£0.30，应查批量条件和优惠日志。均价变化没有识别价格弹性。
5. **如果业务追问“到底投不投”？** 当前不支持直接扩大普惠补贴或为定向优势买单。先给出必须补齐的信息、负责人和改变判断的条件。假设额外实施成本H、覆盖N人、贡献率m，同触达下最低收入优势为H/(N×m)；对照区间决定证据是否够用。无显著性不是零效果的证明。
6. **为什么检测$0.05优势需要约78.1万人？** 这是沿用三臂随机采集与固定策略DR评估的未来总人数，假定pilot方差稳定、双侧α=.05、80%功效，真实优势=.05。不是已做样本，不是每臂人数，也不能套到直接随机两套策略的A/B实验；后者要重新估计方差。
7. **宽窗增长为什么没有结束客户调查？** 固定38人9—11月+1.49%，但11月减额的21人宽窗净减少£46,939，其他17人增加£57,290；21人中18人宽窗仍减少。同客前两月增额封顶匹配只覆盖其11月减额21.06%，不能把他人的增长当作这个客户的恢复。也不能把匹配金额当成已证明的订单提前。
8. **这是不是只挑了支持结论的月份和国家？** 同名单11月−16.32%、10—11月−5.12%、9—11月+1.49%、1—11月−14.37%都保留。宽窗基期与2010年名单选择期重叠，仅为描述。国家采用一致桥接，并报告法国增长及逐一排除每国的敏感性，不删除澳洲来改善总体。
9. **怎样判断大单与广泛价档变化？** 小剪刀83.19%件数集中一张发票；圣诞装饰低价档覆盖172/174名客户，最大订单仅占6.27%。因此分别核查订单条款和广泛促销/商品定义。真实unit_price也不等于挂牌价；不能从两点估计价格弹性。
10. **为什么补贴ROI不能直接乘商家毛利率？** 平台成交额不是平台收入。需要平台佣金/服务收入与实际承担券成本、追回和边际成本；券若已冲减收入不能再扣一次。同发券比例也不等于同核销成本，所以按全策略臂准入用户比较增量净贡献，并设长期窗口防止只提前消费。

原始分录、反证与决策条件见[经营备忘录](../reports/retail_diagnosis/DECISION_MEMO.md)和[营销备忘录](../reports/campaign_decision/DECISION_MEMO.md)。

## 实验与数据方法追问

1. **为什么没有直接预测谁会购买？** 高购买概率可能是自然需求。T-Learner 分别估计各臂收入均值，差值是 CATE；DR-Learner 用训练集交叉拟合的残差构造效果目标。因果评分回答谁受触达影响，仍需留出实验数据验证策略价值。
2. **实验开始前要定什么？** 本次再分析的主要假设是邮件提升每分配用户两周购买率；主指标 conversion，两次邮件对照比较属于同一检验族。访问和收入为辅助指标，收入另用于经济策略目标。明确总体、分配单位、窗口、MDE、停止规则、护栏和多重检验后再开实验。本项目为历史数据再分析，分析计划不能伪称原始实验预注册。
3. **为什么是 ITT？** 以分配臂比较所有客户；是否访问、打开或购买是处理后行为。只比较访问者会引入选择偏差，访问条件转化只能描述漏斗，不能替代总体因果效果。
4. **SRM 与平衡检验有什么区别？** SRM 检查三臂人数是否偏离设计比例；SMD 检查处理前特征差异。二者用于排查分流/数据问题，不证明没有所有偏差，也不因某个协变量 p 值小就认定随机化失败。
5. **MDE 和 Holm 怎么用？** MDE 是预先愿意识别的购买率业务差，不是看到结果后选阈值。样本量结合基线、功效和检验预算计算；两次购买率主比较用 Holm 校正，规划可用 Bonferroni 保守分配 alpha。访问/收入为辅助指标，逐指标两次校正不等于六次比较整体控制。
6. **一年历史消费能做 CUPED 吗？** 它是处理前协变量，可以调整，但与两周结果窗口不同；系数从训练数据学习，不让测试标签参与。是否降方差看实际验证，不能假设相同窗口或保证有效，也不能以历史消费与新结果相减替代增量。
7. **为什么还需要 DR 策略评估？** 预测 CATE 不是真实个体效果。已知各臂概率 1/3，DR 用预测均值加分配一致样本的加权残差，估计固定政策相对不触达的平均收入。随机化支持识别，不需要宣称解决了未知混杂；有限样本模型仍可失误。
8. **证明定向触达更好看哪个区间？** 在验证集选择模型、臂和接触上限，冻结后测试。比较两种政策须对同一用户贡献做差，报告配对差值区间；各自利润区间重叠不是优劣检验。利润情景区间也不证明真实业务盈利，且不覆盖重训/政策选择不确定性。
9. **交易数据清洗最关键是什么？** 一行不是一单；退货需进入净收入，匿名买家不能补 ID。首次观测不是真新客；cohort 起点有左截断，终点有随访不足。完整重复行未必是重复日志，须保留去重假设和金额影响。
10. **你能说熟练 Hive、已经上线吗？** 只按执行证据回答。DuckDB 是本地 SQL 引擎；Spark 启用 Hive 支持不等于 Apache Hive 执行。Hive 要能解释外部表、ORC、分区、动态写入、聚合粒度和运行日志。本项目是独立离线研究；没有真实团队协作、在线实验或部署收益。
