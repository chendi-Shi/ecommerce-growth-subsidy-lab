# 简历项目描述

## 推荐投递版

**电商增长异常诊断与营销投入决策｜独立研究项目**

Python、SQL、Apache Hive、实验分析、因果推断

- 围绕“买家增长、购买金额下降”处理106.7万条真实交易，建立账簿范围、客户结构、商品组合等竞争假设；通过已识别/匿名/退货桥接，发现在2011年11月同比比较中，已识别客户金额下降1.68%时，全体净商品金额实际增长2.34%，修正对整体经营恶化的判断。
- 对历史前1%高购买额名单开展跨月与同客户核查，发现组总增长掩盖18名客户跨窗仍减额；进一步以订单权重拆解国家结构，将海外异常收敛到澳洲集中采购与德国既有买家篮子，并用SKU订单集中度、成交价档覆盖区分大单和广泛价档变化，形成分层核查与干预准入条件。
- 独立复盘6.4万用户随机营销实验，区分平均触达效果与定向额外优势；固定策略后拆解人群/内容选择，估计每名合格用户增量收入差的95%区间为[−$0.279,$0.267]，进一步建立实施成本门槛与未来验证样本量情景，避免将“不显著”解释为无业务价值。
- 实际执行6.4万行Apache Hive分层指标并完成21项对账；交付可复现代码、归因校验与业务备忘录，补贴实验方案明确平台/商家收入、券成本去重、退款成熟、全策略臂ITT及长期购买前移风险。

## 三条精简版

**电商增长诊断与实验决策｜公开数据独立研究**

- 对106.7万条交易开展竞争假设分析，识别已知客户金额−1.68%与全体净商品金额+2.34%的口径反转；以固定名单同客跨月、国家×客户及SKU集中度检验，区分局部订单波动、组间抵消与商品成交价档变化，形成有反证条件的运营建议。
- 复盘6.4万用户三臂随机营销实验，冻结定向策略并做配对评估；将较宽的收益区间映射到成本门槛和后续样本需求，区分“平均触达有效”“定向有额外优势”和“值得额外投入”。
- 使用SQL/Python实现增长诊断与可复现验证，实际运行Hive完成21项指标对账，交付业务决策备忘录及补贴实验迁移方案。

## 面试讲述重心

先讲一个被证据修正的判断：从已识别客户收入下降，追到全体商品账簿仍增长；再发现整组宽窗转正也掩盖同客户跨窗减额，最终定位到具体客户、国家和商品。讲清为什么这些观察不能直接推出“发券可挽回多少收入”。18人是固定名单内21名11月减额客户中，9—11月金额仍减少者；“跨窗”不表示每个月都下降。宽窗基期与名单选择期重叠，因此只作回顾诊断，不能推因果。

实验案例单独讲，不说它验证了UCI客户的策略：原始邮件实验平均有效，但模型定向的额外优势不确定；引入成本门槛后，才知道这个区间能否回答经营问题，以及是否值得继续收集数据。

这是独立研究，未推动真实企业上线或创造已实现补贴收益。时间填写实际投入时间；新增诊断是回顾研究，不宣称预注册。投递前按[面试指南](INTERVIEW_GUIDE.md)复现并讲透相关结果。
