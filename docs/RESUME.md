# 简历项目描述

## 推荐投递版

**电商用户增长与增量营销分析｜独立研究项目**  
Python、SQL、DuckDB、Apache Hive、A/B实验、因果推断

- 处理106.7万条真实交易，构建买家/频次/单均金额与成熟cohort指标；发现11月买家同比增长3.4%而购买金额下降1.7%，通过对数分解定位单均金额下滑，并完成退货/去重审计与RF跨时间验证。
- 分析6.4万用户三臂随机营销实验，完成SRM、处理前平衡、ITT与Holm校正；估计两类内容触达的购买率增量为0.681、0.311个百分点，区分平均营销效果、访问路径与收入结果。
- 实现多臂T-Learner与5折交叉拟合DR-Learner，按60/20/20划分训练/验证/测试；在15.625%触达上限下比较定向、同触达随机与自然购买概率策略，独立测试未发现显著定向优势，据此提出简单策略基线及后续独立验证方案。
- 在Apache Hive4.2.1实际执行6.4万行ODS—ORC分区DWD—ADS指标，完成21项人数与金额对账并保存EXPLAIN；建立利润率/触达成本敏感性分析，输出补贴实验的指标、功效、核销成本与事件合同。

## 空间有限时（三条）

**电商增长与增量营销分析｜公开数据独立研究**

- 使用106.7万条真实交易构建购买增长、成熟cohort与复购体系，完成退货/匿名/去重金额审计及RF分群时间外验证；另以Apache Hive实际运行6.4万行实验指标并完成21项对账。
- 对6.4万用户三臂RCT进行SRM、平衡、ITT及Holm校正，估计内容触达带来0.681/0.311个百分点购买率增量；用处理前历史消费进行协变量调整并检验实际方差变化。
- 训练多臂T/DR-Learner并冻结验证集选择，在1.28万测试用户中配对评估预算策略；未发现定向优于同触达随机的显著证据，形成成本敏感性、盈亏平衡阈值与补贴实验迁移方案。
