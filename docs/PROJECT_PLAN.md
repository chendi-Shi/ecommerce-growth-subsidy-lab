# 电商用户增长与增量营销研究方案

目标是形成逐项可核对的业务分析作品：指标、SQL、统计估计、策略比较、真实结果与后续实验合同。项目采用两套互不关联的真实数据，公开研究不写成实习或上线经历。

## 业务问题与JD对应

|JD要求|本项目实际工作|业务边界|
|---|---|---|
|增长指标体系与模型|交易→订单→用户月，购买用户增长、首次观测/连续购买/回流拆解、客单与购买频次、cohort复购|观察到的买家增长，不是DAU或注册拉新|
|人货场刻画|成熟cohort、时间外验证RFM、商品代码/价格带/国家；实验历史渠道与内容分层|国家与历史渠道是可观测代理，缺少短视频/直播/商城归因|
|评估增长策略效果|真实三臂RCT，SRM/平衡、ITT/Holm、前置消费调整、收入与购买率分别推断|真实邮件触达，不冒充补贴/广告投放|
|提升策略效率|T/DR-Learner；训练/验证/测试；冻结策略后与同触达随机/购买概率基线配对比较|无显著优势也保留；触达预算不等于核销预算|

## 交易增长分析

两张年度工作表全量读取，记录文件来源/哈希和工作表行数。流水无原始唯一行键，完全相同八字段去重作为假设，并报告去重前后金额差。收费代码与商品行区分，保留负数贷项/取消和匿名客户金额；用户统计只用正向、可识别购买。

订单粒度为客户与发票，用户月粒度去重买家。月收入恒等于买家数×人均订单数×订单均价；变化使用对数精确分解，并校验三项之和等于收入对数变化。买家按首次观测、上月也购买、此前买过但上月未买拆分。起点之前行为未知，首次观测不称新注册客户。

留存表仅显示已成熟窗口，未成熟单元为空。30/60/90天累计再次购买使用对齐的完整90天cohort比较，各口径公开可用人群数。RFM特征只取2011年8月底前交易：R/F分位规则决定分群，M用于价值刻画；9—11月购买表现用于时间外描述验证，是风险/价值分层而非因果响应分层。产品价格带、国家收入与集中度用于提出机会，观察相关性不能认定营销增量。

## 随机实验分析

Hillstrom64,000名此前12个月内购买过的存量客户，各1/3分配无邮件/男装内容/女装内容，结果窗口两周。仅处理前历史、渠道与购买标记进入特征，处理后访问/购买/消费禁入。无原始客户ID，本地行号只作防重复和实验划分键。

主要结果为两周购买率的两次对照比较，Holm校正；收入、访问为辅助结果，分别明确检验家族。95%区间是单比较nominal区间，不称同时95%区间。这是既有数据回顾研究，当前指标选择不是2008年原实验的预注册记录。

用户60/20/20分割仅按处理臂分层，不能用结局分层。60%训练收入T-Learner（Ridge/RandomForest）及5折交叉拟合DR-Learner；20%验证选择内容、模型、触达深度；20%测试评估冻结策略。10,000/64,000触达上限是显式业务案例假设。

采用已知随机化概率的逐用户DR得分，HT作对照；同用户策略得分之差形成配对区间。随机基线用概率混合报告期望效果，减少额外抽样噪声。自然购买概率模型在控制组训练，使用同触达数量，区分本来会买与触达增量。个体四种潜在响应类型不可观测。测试样本只有124次购买，稀疏重尾收入限制分层和定向优势检验；不得根据测试表现再改seed或阈值。

利润率和成本未观测，因此只报告假设网格下净贡献、盈亏平衡成本和区间。购买/消费为实测，经济情景为参数化推演，分别保存；不能写成真实补贴ROI改善。

## 复现与业务交付

SQL、下载器、源校验、聚合CSV、统计JSON、图表、Hive证据和测试构成追溯链。原始记录、行级预测和数据库不上传。单命令顺序运行两项研究；Hive由显式选项或GitHub Actions执行。

产品、算法、研发的待实施方案见[EXPERIMENT_DESIGN.md](EXPERIMENT_DESIGN.md)：准入、随机化、成本、窗口、功效、护栏、分组及券订单事件。真实业务先补齐合同并独立验证，再决定定向模型是否值得上线。

## GitHub调研与改进

- [电商离线数仓](https://github.com/114520839/ecommerce-offline-datawarehouse)：参考ODS/DWD/ADS和指标结构。本项目明确发票行、订单及用户粒度，保存实际执行/对账结果。
- [促销评估项目](https://github.com/hanyanzeduck/ecommerce-promotion-evaluation-system)：参考促销问题。本项目使用真实RCT，实际训练和测试策略，不以规则或常量代替统计结果。
- [scikit-uplift](https://github.com/maks-sh/scikit-uplift)：参考多处理Uplift与Hillstrom来源。自行实现多臂DR、验证选择和经济决策，保留不显著比较。
- [Apache Hive](https://github.com/apache/hive)：使用官方发布容器实际执行。代码为原创实现，未复制上述分析仓库代码。
